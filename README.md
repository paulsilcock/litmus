# Litmus

A framework for building applications with agentic AI capabilities.

## Prerequisites

- [Vite+](https://viteplus.dev/) v0.1+

```sh
curl -fsSL https://vite.plus | bash
```

Vite+ manages Node.js and package installation, so no other global dependencies are needed.

## Setup

```sh
vp install
```

## Development

```sh
vp test       # Run tests
vp lint       # Lint code
vp fmt        # Format code
vp check      # Format, lint, and type checks
```
